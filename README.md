# AURELIA — Luxury SPA Website

A polished frontend-only SPA portfolio project built with Next.js, JavaScript, React and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included
- Responsive luxury/minimalist design
- Sticky responsive navigation + mobile menu
- Hero, About, Services, editorial treatment sections, Products, Consultation, Testimonials, FAQ, Contact and Footer
- Frontend-only login/account demo with localStorage
- Booking flow gated by login, local booking storage and generated reference
- Consultation request stored locally
- Newsletter validation + localStorage
- Product detail modal / demo bag interaction
- Member benefits state
- `prefers-reduced-motion` support
- No backend, database, authentication server or booking API

## Notes
- This is intentionally frontend-only. Login, bookings, consultations and newsletter subscriptions are demonstrations and are stored in browser localStorage.
- Replace placeholder contact information and sample content before production use.
- Remote Unsplash images are used for the demo visuals and the supplied logo URL is used directly.
